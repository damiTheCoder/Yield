# YIELD

YIELD is a Vite, React, TypeScript, and Tailwind CSS app for Liquidity Funded Tokens, CoinTags, asset hunting, and token financial dashboards.

## Development

```sh
npm install
npm run dev
```

## Production Build

```sh
npm run build
npm run preview
```

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn-ui
